# 库存模块 · 需求（2026-09-21 人口述）

原材料管理：建一次，选原料，填单位、分类。
每日入库：选原料 → 输数量 → 输单价 → 保存。
每日出库 / 盘点：
- 方式一：直接填今天用了多少。
- 方式二：盘点还剩多少，系统倒推今天用了多少。
库存查看：当前还剩多少，库存价值多少。
低库存提醒：低于安全线时提醒补货。
盘点差异：账面和实际不一致时，自动记录差异，不要求填原因。

## 实现口径（V1）
- 原料建档：名称 / 单位 / 分类 / 安全线，建一次反复用。
- 库存量直接记在原料上；三种动作都会写流水（moves）：
  - 入库 in：+数量，记单价（库存价值按最近一次进价估算）；
  - 用量 use：−数量（方式一，直接填用了多少）；
  - 盘点 count：填实际剩余 → 倒推用量 = 原库存 − 实际，差额自动记为差异（可正可负，不填原因）。
- 库存价值 = Σ 当前库存 × 最近进价。
- 低库存 = 当前库存 < 安全线：库存页红色标出 + 概览提醒。
- 盘点差异自动入流水（时间、原料、账面、实际、差多少），不强制填原因。
- V1 不做：配方联动（卖一道菜自动扣原料）、多仓、供应商。
