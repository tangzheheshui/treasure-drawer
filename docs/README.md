# 文档索引 · 百宝抽屉

下一步敲什么 → 敲 `/app`（无参数）。文件登记表如下，没登记的文件进不来，进度列写错会被 doctor 当场报出来。

| 编号 | 文件 | 谁看 | 目标 | 什么时候打开 | 进度 |
|---|---|---|---|---|---|
| 1 | `requirements.html` | 你 | 只写做什么/不做什么，定方向盘；`doctor --req` 全过 | 想砍功能或加功能时翻 | 已有 |
| 2 | `app.html` | 你 | 能点的原型，先灰白后定稿换肤；`doctor --proto` 全过（ui 定稿后 `--ui` 再过） | 评审交互流程、以后对照施工时点开 | 待产出 |
| 3 | `brief.md`（ai/） | 我 | 选型（组件库+版本+交付形态）+ 页面清单；`doctor --scope` 过 | 画原型前、施工装库前 | 待产出 |
| 4 | `flow.md`（ai/） | 我 | 页与页之间怎么走的唯一归属 | 施工对照页面跳转时 | 待产出 |
| 5 | `notes.md`（ai/） | 我 | 每页内部行为与状态的唯一归属 | 施工对照页面细节时 | 待产出 |
| 6 | `decisions.md`（ai/） | 我 | 拍过的板 + 否掉的选项及理由 | 防止把否掉的东西再提一遍 | 待产出 |
| 7 | `spec.md`（ai/） | 我 | 数据契约（实体/状态机/操作映射）；`doctor --lock` 过 | 施工数据层时当验收清单 | 待产出 |
