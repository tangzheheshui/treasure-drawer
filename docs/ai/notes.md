# 页内行为与状态 · 百宝抽屉

页间跳转归 flow.md，本文件管每页内部。页名与 `app.html` 的 `data-page` 逐字一致。

## 全局行为

- 壳：手机 390×844 机身；底部 2 个页签「抽屉 / 工具库」，互切不进返回栈
- 专注模式：12 个工具页与整理抽屉进入时藏页签，页内只留一条极简顶栏（返回 + 工具名 + 收藏切换）；记分牌与模拟来电在此基础上更进一步（全屏无表单感）
- 返回：一层返回栈，回到进入时的来路页
- 收藏切换：顶栏 ☆/★ 即收进抽屉 / 移出抽屉，toast 反馈
- 数据：原型用 localStorage 演示持久（收藏、整理顺序、心愿）；工程阶段换 IndexedDB 适配器
- 验收导航条：页面跳转直达、三态演示（空 / 加载 / 错误，可驻留），定稿后删
- 视觉：灰白形态打底，配色定稿归 `/app ui`

## 弹层（4 个，全部真内容）

| 弹层 | 内容 | 怎么关 |
|---|---|---|
| 设置菜单 | 心愿池 / 关于 / 恢复默认收藏 | 遮罩或取消 |

| 通用确认 | 文案按场景换（移除收藏 / 重置比分） | 取消 / 确认执行 |

## 逐页行为

### 抽屉首页
- 收藏宫格 2 列（图标 + 名称，不带描述）；把手栏可收起 / 展开；收起态 = 常用横滚条一行
- 「整理」进整理抽屉；右上 ⚙ 开设置菜单；去工具库走底部页签，不设入口卡
- 空：收藏删光后引导卡去工具库；加载：首开骨架；错误：存储读不出给「恢复默认收藏」

### 工具列表
- 三组分段（日常 / 效率 / 现场）+ 搜索框；一行一条：图标 + 名称，行右侧收藏图标「＋ / ♥」切换
- 空 = 搜索无结果（文案与收藏空态不同）；加载 = 骨架行；错误 = 存储不可用横幅（收藏动作禁用）

### 整理抽屉
- 收藏列表行内 ↑ / ↓ / ✕（移除走通用确认）；完成回抽屉首页
- 空：抽屉空着，提示先去收工具

### 二维码生成
- 文本域 + 尺寸三档（小 / 中 / 大）；内容为空时生成钮禁用并出提示条
- 内容超出演示上限（1000 字）出错误条；生成 = 确定性伪点阵画布（三个定位角 + 哈希点阵），工程阶段接真编码库
- 保存图片为演示 toast

### 密码生成
- 长度滑杆（8–64）+ 四类字符勾选；全部不勾时生成钮禁用并出提示条
- 长度超过 48 位结果换行并出「已换行显示」提示；强度条按字符集与长度算三档

### 单位换算
- 分组三段（长度 / 重量 / 温度）+ 双向单位选择 + 双输入框即时互算；温度按公式特判
- 输入非数字出错误条，输出侧清空

### 颜色转换
- 输入 HEX 或 rgb() 任一格式，出三行互转结果（各带复制）+ 色块预览
- 识别不了出错误条并给「填入示例」；三条结果都可复制

### 擦图
- 初始是空态引导「选一张示例图开始」；选后进入画布，软边笔刷涂抹即抹除
- 笔刷三档粗细；「换一张」重画示例图；涂抹痕迹在换图前保留

### 字数统计
- 粘贴即统计：字符 / 汉字 / 英文词 / 段落 / 行五行实时刷新
- 未输入时空态提示；「填入示例 / 清空输入」辅助

### 文本对比
- 左右两栏 + 对比钮；结果逐行标增 / 删 / 同三色；「交换两栏」一键换位
- 两栏未齐时空态；任一栏超过 500 行出截断提示，只比前 500 行

### 倒计时番茄钟
- 预设 25 / 5 / 10 分钟 + 自定义分钟数；未选时长时开始钮禁用并出提示条
- 开始后大字倒计时，可暂停 / 重置；归零震动 + toast「时间到」；离开页面计时清掉

### 随机抽签
- 两模式：随机数（范围掷一次）/ 名单抽签（贴名单，抽一个，抽过不再中）
- 名单为空时空态引导 +「填入示例」；抽完自动从名单移除，重置靠重新填入

### 记分牌
- 红蓝两队各一个大数字，加 / 减各一键；领先的队名亮起
- 重置比分走通用确认；本页无空加载错误态（本地即时计算）

### 模拟来电
- 表单：来电人 / 号码 / 延迟秒数（3 / 5 / 10）+「开始响铃」
- 响铃 = 全屏仿来电界面（头像取姓名首字、脉冲动画、尝试震动），接听进步长计时，挂断回表单
- 响铃中是业务态，不属六态演示

### 尺子
- 横向刻度尺画布，默认 96dpi 换算；校准滑杆（30–50 px/cm）实时重画
- 校准提示：拿银行卡长边（85.6mm）贴屏对齐；「重置校准」回默认

## 原型与工程的差距

- 二维码是确定性伪点阵，工程接 `qrcode` 真编码；擦图是软边涂抹演示，工程先做轻擦除（模糊 / 涂抹），内容感知填充待定
- 排序用上移 / 下移按钮演示，工程可加拖拽；震动 API 在不支持的设备静默失败
- localStorage 仅演示持久；工程换 IndexedDB 适配器（隐私模式降级内存实现）
