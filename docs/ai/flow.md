# 页面跳转 · 百宝抽屉

页与页之间怎么走的唯一归属。页内行为与状态归 notes.md。

## 跳转图

```mermaid
graph LR
  subgraph 底部 Tab（互切，不进返回栈）
    HOME[抽屉首页] <--> TOOLS[工具列表]
  end
  HOME -- 宫格选工具 --> FOCUS[12 个工具页]
  TOOLS -- 列表选工具 --> FOCUS
  FOCUS -- 返回（按来路） --> HOME
  FOCUS -- 返回（按来路） --> TOOLS
```

## 弹层（不换页，盖在所属页上）

| 弹层 | 从哪打开 | 关闭去向 |
|---|---|---|
| 设置面板 | 抽屉首页右上 ⚙，右侧滑出 | 遮罩或 ✕ 回抽屉首页 |
| 意见反馈 | 设置面板 | 取消回面板，提交后自动关 |
| 购买支持 | 设置面板 | 先不了回面板，购买 toast 后自动关 |
| 关于 | 设置面板 | 关闭回面板 |
| 通用确认 | 记分牌「重置比分」 | 取消或确认后留在原页 |

## 返回规则

- 工具页进返回栈；底部 Tab 互切不进栈
- 返回 = 回到进入时的来路页（抽屉首页或工具列表），不是固定回首页
