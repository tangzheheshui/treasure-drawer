# 页面跳转 · 百宝抽屉

页与页之间怎么走的唯一归属。页内行为与状态归 notes.md。

## 跳转图

```mermaid
graph LR
  subgraph 底部 Tab（互切，不进返回栈）
    HOME[抽屉首页] <--> TOOLS[工具列表]
  end
  HOME -- 宫格或横滚选工具 --> FOCUS[12 个工具页]
  TOOLS -- 列表选工具 --> FOCUS
  FOCUS -- 返回（按来路） --> HOME
  FOCUS -- 返回（按来路） --> TOOLS
  HOME -- 整理 --> EDIT[整理抽屉]
  EDIT -- 完成 --> HOME
```

## 逐页进出

| 页面 | 从哪进来 | 能去哪 |

## 弹层（不换页，盖在所属页上）

| 弹层 | 从哪打开 | 关闭去向 |
|---|---|---|
| 设置菜单 | 抽屉首页右上设置 | 回抽屉首页 |
| 心愿池 | 设置菜单 | 许愿、撤下或关闭都留在弹层，关闭回设置菜单 |
| 关于 | 设置菜单 | 关闭回设置菜单 |
| 通用确认 | 整理抽屉「移除」、记分牌「重置比分」 | 取消或确认后留在原页 |

## 返回规则

- 工具页与整理抽屉进返回栈；底部 Tab 互切不进栈
- 返回 = 回到进入时的来路页（抽屉首页或工具列表），不是固定回首页
