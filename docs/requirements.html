需求（方向盘）· 百宝抽屉

给日常与现场场景用的个人小工具抽屉：常用工具收藏即取，进工具即全屏专注。手机优先，Web 与手机同一应用，数据只存在本机。

本文件只写「做什么 / 不做什么」，是方向盘；交互与页面的细节在 ai/notes.md、ai/flow.md，数据与选型在 ai/spec.md、ai/brief.md。

MVP（做完打勾）

  • 抽屉收藏列表：只展示收进来的工具，点 ♥ 移出
  • 从工具库把工具收进抽屉
  • 工具库浏览：日常 / 效率 / 现场 三组分组与搜索
  • 工具专注模式：进入工具后全屏极简，只留返回与收藏切换
  • 收藏数据本地保存（换设备不跟随）
  • 个人资料（头像与昵称，只存本机）与设置侧滑面板
  • 意见反馈：写了就复制，粘给开发者
  • 购买支持：工具永久免费，自愿请开发者（原型不接真支付）
  • 收费工具：¥ 角标，未登录点开先引导登录解锁（支付与短信工程阶段接）
  • 登录与退出登录：账号只为收费解锁，收藏数据仍只存本机
  • 工具：二维码生成
  • 工具：强密码生成
  • 工具：单位换算（长度 / 重量 / 温度）
  • 工具：颜色值互转（HEX / RGB / HSL）
  • 工具：擦图（抹除图片里不需要的部分）
  • 工具：字数统计
  • 工具：文本差异对比
  • 工具：倒计时与番茄钟
  • 工具：随机数与名单抽签
  • 工具：记分牌（红蓝两队计分）
  • 工具：模拟来电
  • 工具：屏幕尺子

明确不做（本版不做，含理由）

  • 自定义网址条目 （首批只收内置工具，保证工具库质量；扩展池再议）
  • 收藏备份的导出导入与云备份 （个人纯本地用不上，设置更简；真要跨设备时走扩展池云同步）
  • 云同步与云端数据 （登录只为收费工具解锁，收藏数据仍只存本机；全量云同步在扩展池，接已有 PocketBase）
  • 原生 App 套壳 （纯 Web 先行验证产品，套壳进扩展池）
  • 广告与付费墙 （工具全部永久免费；「购买支持」只是自愿请咖啡，不锁任何功能）
  • 使用行为统计与上报 （本地工具不做行为收集）
