# 需求 · 尺子（ruler）

2026-09-20 人口述。全屏直尺，永远沿屏幕最长边量。
2026-09-20 二轮反馈改：单边刻度、真机自动定标不可调、横拿文字正对持机人。

| # | 需求 | 说明 |
|---|---|---|
| 1 | 全屏直尺 | 满屏画布，永远沿屏幕最长边：竖拿贴左缘、0 点在上；横拿贴上缘、0 点在左 |
| 2 | 单边厘米刻度 | 只有量测这一条长边有刻度（cm）：1mm 细 / 5mm 中 / 1cm 粗带数字 |
| 3 | 真实尺寸自动定标 | 刻度固定代表真实物理长度，按本机屏幕 PPI 自动换算（内置常见 iPhone/iPad 机型表，未识别按屏幕密度估算），**没有校准滑杆、不可调、不存 localStorage** |
| 4 | 文字朝向 | 刻度数字永远立正对着持机人（横拿时与最长边垂直），不跟着尺身转 |
| 5 | 全屏按钮 | ⚙ 面板里一键全屏；面板同时展示识别到的机型/PPI 与「1 厘米 ≈ 多少像素」供核对 |

不做什么：英寸刻度（人拍板单边就够）、校准滑杆（刻度必须真实固定，不可调）、角度测量、拼接连尺（后置）。
