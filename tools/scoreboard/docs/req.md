# 需求 · 计分板（scoreboard）

2026-09-20 人口述。酒桌/球局的翻页计分牌，界面越简洁越好。

| # | 需求 | 说明 |
|---|---|---|
| 1 | 横屏对垒 | 左边一个分数、右边一个分数；竖屏给「请横屏」提示 |
| 2 | 翻页加分 | **往上翻 = 加分，往下翻 = 减分**（默认一次 ±1）；**可以翻到负分** |
| 3 | 跟手翻页 | **台历式**：纸页挂顶部装订轴，绕**顶轴**翻过去/翻回来（不是翻牌钟的分半翻转）；跟手指走，松手过阈值翻页、不过弹回 |
| 4 | 极简界面 | 平时不显示任何按钮；单击屏幕呼出「返回 / 归零」条 |
| 5 | 记忆 | 比分存 localStorage，关页不丢 |

不做什么：统计（人明确先不做）、三方计分、回合记录（后置）。
