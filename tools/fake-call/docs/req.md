# 需求 · 模拟来电（fake-call）

2026-09-20 人口述。模拟 iPhone 的来电效果（人明确：要 iPhone 的样子）。

| # | 需求 | 说明 |
|---|---|---|
| 1 | 设置 | 来电人姓名、几秒后来电（默认 3 秒）、响铃+震动开关；设置存 localStorage |
| 2 | 倒计时可取消 | 等待期显示「N 秒后来电」，可取消 |
| 3 | 来电锁屏 | iPhone 锁屏风格：深色渐变壁纸、时间日期、头像+姓名+「iPhone」、红色拒绝 / 绿色接听大圆钮 |
| 4 | 铃声 | WebAudio 合成三音上行循环（零素材零依赖）+ 手机震动（Android） |
| 5 | 通话中 | 接听后计时 mm:ss，静态功能按钮网格 + 大红「结束」钮 |

不做什么：真拨号、伪造通知推给系统、录音（永不做）。
