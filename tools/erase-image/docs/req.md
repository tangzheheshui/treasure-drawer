# 需求 · 图片擦除（erase-image）

2026-09-20 人口述（语音），AI 理顺后人点头「开工」。定位：擦掉图上不想要的东西，纯色背景水印是第一场景。工具叫「图片擦除」，不叫「去水印」。

## 做什么（v1）

| # | 需求 | 说明 |
|---|---|---|
| 1 | 打开图片 | 手机选相册/拍照，电脑支持拖拽、粘贴；纯本地处理，不上传 |
| 2 | 吸管取色 | 点吸管 → 在图上点一下取该点颜色，取完自动切回笔 |
| 3 | 笔刷涂抹 | 粗细可调的笔把水印盖掉。笔迹默认「智能取样」：颜色自动贴近笔迹周边底色、带底噪，不是死色；手动取色后改用固定色 |
| 4 | 橡皮 | 把涂过的区域恢复成原图 |
| 5 | 手势 | 手机：单指涂、双指缩放/平移；电脑：滚轮缩放（以光标为中心）、空格/中键拖拽平移、触控板捏合缩放 |
| 6 | 撤销/重做 | 以笔为一步 |
| 7 | 保存 | 永远另存新图，不碰原图；PNG 保持 PNG，其余 JPEG 0.95 |

## 不做什么（明确后置，防跑偏）

| 项 | 去向 |
|---|---|
| 渐变/复杂背景擦除（内容感知填充） | v2 |
| 点一下自动圈选擦（「魔法擦」） | v2 |
| 批量处理 | v3 |
| 自动草稿/关页恢复 | v2 再议 |
| 账号/收费逻辑 | 外壳管：本工具在外壳里是 ¥ 收费工具，工具页自身不感知钱 |
| 图片上传/云处理 | 永不（纯本地是全 app 底盘） |

## 边界

- 超大图：长边压到 4096px 内处理，提示一句「已缩放到 N×N」，导出即处理尺寸。
- v1 无持久化：关页即丢，导出靠保存。
