# 页内行为与状态 · 图片擦除

单页工具：上=画布区（深灰衬底、满幅），下=工具栏一条（白底、安全区适配）。

## 状态矩阵

| 状态 | 进入 | 表现 | 出口 |
|---|---|---|---|
| 空态 | 首次进入 | 中央「打开图片」大按钮；电脑可拖拽/粘贴 | 选图 → 编辑态 |
| 编辑态 | 图已载入 | 画布显示图，工具栏可用；默认笔工具 | 保存 / 换图 |
| 吸管模式 | 点吸管（按钮高亮） | 电脑光标变十字；点下取色、Toast 报色值、自动切回笔 | 取色完成 / 再点吸管取消 |
| 笔模式（默认） | 载入后默认 | 单指按下即涂 | 切工具 |
| 橡皮模式 | 点橡皮 | 涂过处恢复原图 | 切工具 |
| 保存完成 | 点保存 | 生成新图下载，Toast「已保存」 | 留在编辑态 |

## 行为细节

- 智能取样：每个落点在已涂层上取两圈环带样本，与被盖像素（原图落点色）明显不同（距离 >60）的样本视为背景候选，够数取其均值、不够取全部均值 + 微噪声；手动取色则固定色直涂。
- 撤销/重做：每笔存落笔前后各自外接矩形像素补丁，上限 50 步；双指切进时当前未完成笔整笔回退（不算一步）。
- 粗细滑杆：选中笔/橡皮时在工具栏上方出现，范围 4–120（图片坐标）。
- 手势：双指捏合以中点缩放、随中点平移；电脑滚轮缩放、空格或中键拖拽平移、Ctrl+滚轮=触控板捏合。
- 保存：文件名 `<原名>-erased.<png|jpg>`，走浏览器标准下载。
- 视觉：跟随外壳基线——白底、近黑主色、灰分隔；画布衬底深灰。
