# 需求 · 摇骰子（dice）

2026-09-20 人口述。酒桌骰盅，人点名要 3D 的真实感（AI 评估：Three.js + cannon-es 轻量物理可做，不用游戏引擎，人拍板做）。
2026-09-20 二轮反馈：不要穿模、能盖着也能掀开、画面要亮。
2026-09-20 三轮反馈：落点要更随机、盅和桌要像真的（上材质）、盅加高、镜头拉远。

| # | 需求 | 说明 |
|---|---|---|
| 1 | 3D 骰子 | 真实立方体骰子（象牙白、1/4 红点的中式骰子），物理引擎随机翻滚落地 |
| 2 | 骰盅 | 点「摇」：骰盅盖下 → 摇晃（骰子跟着乱撞）→ 扣住停稳，结果保密 |
| 3 | 上划开 / 下划盖 | 盖着时上划掀盅报点数；开着时下划盖回收回点数；盖着可直接再摇（开着再摇先自动盖回） |
| 4 | 不穿模 | 骰子物理围栏 = 盅口内径（十二边形），落点永远出不了盅；盅只竖直砸 + 微晃（幅度小于预留壁隙），壁永不扫过骰子；掀盅/盖回先竖直升降再平移，不剐蹭 |
| 5 | 不重叠 | 落点间距约束 + 停稳检查：歪放/互叠/出圈轻推重停两次，仍不行趁盖着暗中摆正兜底 |
| 6 | 落点随机 | 随机撒点 + 成对推开的散点布局（每局都不同），摇盅力度逐拍随机；盅口与落点间留足盖住余量 |
| 7 | 像真的 | 骰盅：锥形亮漆杯身 + 圆顶 + 口沿卷边（clearcoat 塑料）；木桌+毛毡程序纹理；环境反射 + 软阴影；盅加高、镜头拉远一点 |
| 8 | 盅要罩得住 | 骰盅半径随骰子数自适应（罩住全部落点再留余量），1–9 颗都盖得严实 |
| 9 | 默认 5 个 | 骰子数量可调 1–9，默认 5 |
| 10 | 声音 | 碰撞有骰子声（WebAudio 合成噪声脉冲，随撞击力度变响），开盅有叮；可静音 |
| 11 | 报点 | 开盅后中央大字「N 点」，盖回即隐藏 |
| 12 | 明亮清晰 | ACES 调色 + 主光/逆光/半球光打亮，红点高饱和正红，不雾蒙蒙 |

不做什么：联机对战、下注筹码、骰子皮肤商店（后置）。

技术：three（渲染）+ cannon-es（物理，gzip ~30KB），骰面点数为 3D 凸点几何（顶点色），无建模资源、无贴图。
